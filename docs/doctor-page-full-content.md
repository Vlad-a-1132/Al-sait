# Страница врача Абрамова — полная структура, все тексты, цены и анимации

Документ описывает всё содержимое начиная с блока-обёртки секций (класс `overflow-x-hidden rounded-[24px] border border-slate-100 bg-white shadow-[0_20px_60px_rgba(15,23,42,0.08)] p-6 md:p-8`): структура, все тексты, все цены по направлениям, FAQ, отзывы и полные определения анимаций (CSS и Framer Motion).

---

## 1. Обёртка секции (SectionShell)

Каждая секция страницы обёрнута в:

```html
<section id="…">
  <motion.div
    class="overflow-x-hidden rounded-[24px] border border-slate-100 bg-white shadow-[0_20px_60px_rgba(15,23,42,0.08)] p-6 md:p-8"
    variants={vSection}
    initial="hidden"
    whileInView="show"
    viewport="{{ once: true, amount: 0.2 }}"
  >
    <!-- содержимое секции -->
  </motion.div>
</section>
```

Анимация: Framer Motion `vSection` (появление при скролле). Без пресетов анимация не сработает.

## 10. Анимации (Framer Motion) — полные пресеты

Чтобы все анимации работали, в проекте должен быть модуль с `makeMotionPresets`. Ниже — полный набор вариантов (нормальный и reduced-motion).

```ts
"use client";

const duration = 0.45;
const ease = [0.25, 0.46, 0.45, 0.94] as const;

export function makeMotionPresets(reducedMotion: boolean) {
  if (reducedMotion) {
    return {
      vSection: { hidden: { opacity: 1 }, show: { opacity: 1 } },
      vCard: { rest: {}, hover: {} },
      vBtn: { rest: {}, hover: {}, tap: {} },
      vIcon: { rest: {}, hover: {} },
      vSwap: { initial: { opacity: 1 }, animate: { opacity: 1 }, exit: { opacity: 1 } },
      vStagger: { hidden: {}, show: {} },
      vReveal: { hidden: { opacity: 1, y: 0 }, show: { opacity: 1, y: 0 } },
    };
  }
  return {
    vSection: {
      hidden: { opacity: 0, y: 12 },
      show: { opacity: 1, y: 0, transition: { duration, ease } },
    },
    vCard: {
      rest: { scale: 1, y: 0 },
      hover: { scale: 1.02, y: -2, transition: { duration: 0.35, ease } },
    },
    vBtn: {
      rest: { scale: 1 },
      hover: { scale: 1.02, transition: { duration: 0.3 } },
      tap: { scale: 0.98 },
    },
    vIcon: { rest: { rotate: 0 }, hover: { rotate: 3 } },
    vSwap: {
      initial: { opacity: 0, x: -8 },
      animate: { opacity: 1, x: 0, transition: { duration, ease } },
      exit: { opacity: 0, x: 8, transition: { duration: 0.3 } },
    },
    vStagger: {
      hidden: { opacity: 0 },
      show: (i: number) => ({ opacity: 1, transition: { delay: i * 0.06, duration } }),
    },
    vReveal: {
      hidden: { opacity: 0, y: 14 },
      show: { opacity: 1, y: 0, transition: { duration, ease } },
    },
  };
}
```

Где что используется:

- **vSection** — обёртка каждой секции (SectionShell).  
- **vCard** — кнопки направлений в списке.  
- **vBtn** — кнопки «Записаться», «Записаться на консультацию», «Посмотреть полный прайс» и т.п.  
- **vIcon** — иконка/стрелка у пункта направления на десктопе.  
- **vSwap** — смена контента превью при выборе другого направления (AnimatePresence + key=activeId).  
- **vReveal** — появление блоков в DirectionDetails, AdvantagesBlock, FaqByDirection, PricingByDirection, ReviewsStrip, FinalCtaCard.
